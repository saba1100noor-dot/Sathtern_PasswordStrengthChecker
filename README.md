# Sathtern Password Strength Checker

## 📌 Project Overview

The Sathtern Password Strength Checker is a simple Python-based cybersecurity tool that evaluates password strength and provides suggestions for improving password security.

This project was developed as part of the **Sathtern Virtual Internship Program – Cyber Security Track**.

## 🔐 Features

* Checks password length
* Detects uppercase letters
* Detects lowercase letters
* Detects numbers
* Detects special characters
* Identifies commonly used weak passwords
* Classifies passwords as Weak, Medium, Strong, or Very Weak
* Provides suggestions to improve password security

## 🛠️ Technologies Used

* Python
* Regular Expressions (`re`)

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python password_checker.py
```

5. Enter a password when prompted.

## 🧪 Example

### Weak Password

```text
Enter your password: password

Password Strength: Very Weak

Suggestions:
- This is a commonly used password. Choose a more unique password.
```

### Strong Password

A password containing sufficient length, uppercase and lowercase letters, numbers, and a special character can be classified as **Strong**.
